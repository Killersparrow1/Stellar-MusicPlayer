# StellarSound Music Player

A beautiful **glassmorphic** web-based music player for local audio files.

[![Screenshot.png](https://i.postimg.cc/0Ns9Ywsd/Screenshot.png)](https://postimg.cc/CRcyYddz)


---

## Features

- **Glassmorphic UI** with stellar background effects  
- **Supports multiple audio formats**: MP3, FLAC, WAV, OGG, AAC, M4A  
- **Local file system access** for your music collection  
- **Responsive design** that works on different screen sizes  
- **Modern typography** and **SVG icons**  

---

## Usage

1. Open the `index.html` file in a web browser.  
2. Click **"Select Music Directory"** and choose your audio folder.  
3. Select any track from the playlist to start playing.  

---

## Technical Notes

- Runs entirely in your web browser.  
- No server installation required.  
- Works offline after initial load.  
- File access uses standard browser APIs.
